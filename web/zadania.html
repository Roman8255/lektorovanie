Praktické zadania

Projektové zadania pre prvákov

Vyber si jednu z troch možností a priprav web, ktorý bude vyzerať ako reálny mini projekt. Cieľom je precvičiť HTML štruktúru, CSS layout, prácu so sekciami a pri pokročilejších variantoch aj základnú interaktivitu.

Možnosti A, B, C Možnosť A Možnosť B Možnosť C Checklist a body

01

Vyber si svoju úroveň

Zadania sú rozdelené do troch úrovní. Ak si si ešte neistý v HTML a CSS, začni možnosťou A. Ak už chceš skúsiť aj JavaScript alebo vlastný nápad, prejdi na B alebo C.

Možnosť A

Mini e-shop landing page

Jedna moderná produktová stránka pre jeden produkt. Fokus na layout, obsah, sekcie a príjemný vizuál.

Možnosť B

Produktová stránka + interaktivita

Klasická produktová stránka rozšírená o galériu, výber variantu a tlačidlo do košíka s jednoduchou JS logikou.

Možnosť C

Vlastný mini startup projekt

Vlastná téma, vlastný obsah a aspoň jedna interaktívna časť. Môžeš urobiť e-shop, portfolio, reštauráciu alebo app landing.

02

Možnosť A: Mini e-shop landing page

Ideálne zadanie po základoch HTML a CSS. Cieľ je vytvoriť jednu prehľadnú a peknú stránku, ktorá pripomína reálny produktový web.

Čo musí stránka obsahovať

  • Header s názvom e-shopu a jednoduchým menu.
  • Hero sekciu s veľkým nadpisom, popisom a CTA tlačidlom.
  • Produktovú časť s obrázkom, názvom, cenou a popisom.
  • Sekciu výhod aspoň v 3 bodoch.
  • Footer s kontaktom, fake emailom a copyright textom.

Nápady na produkt

gaming myš slúchadlá sneakers iPhone výberová káva meme produkt
Cieľ projektu

Stránka má pôsobiť ako reálny landing page. Dôležité sú medzery, kontrast, poradie sekcií a čitateľnosť.

03

Možnosť B: Produktová stránka + interaktivita

Pre študentov, ktorí už zvládnu základnú štruktúru a chcú si vyskúšať prvé JavaScript správanie na stránke.

Povinné časti

  • Galéria obrázkov produktu s kliknutím na náhľad.
  • Tlačidlo Pridať do košíka s alertom alebo textovou správou.
  • Výber variantu produktu, napr. farba alebo veľkosť.
  • Produktový detail s cenou, popisom a výhodami.

Čo sa tým precvičí

DOM a onclick

Zmena obrázka, textu alebo stavu po kliknutí.

Premenné a podmienky

Jednoduchá logika pre varianty, cenu alebo počet kusov.

Kompletnejší UI flow

Už to nie je len statická stránka, ale malý produktový zážitok.

04

Možnosť C: Vlastný projekt

Najvoľnejšia varianta pre šikovnejších študentov. Téma je na nich, ale výstup musí stále vyzerať ako premyslený webový projekt.

Príklady tém

  • mini e-shop
  • osobné portfolio
  • reštaurácia alebo kaviareň
  • fake startup landing page
  • jednoduchá app prezentácia

Minimálne požiadavky

  • aspoň 3 samostatné sekcie
  • vlastný obsah a vlastný vizuál
  • aspoň 1 interaktívny prvok v JavaScripte
  • zreteľné CTA alebo hlavný cieľ stránky

Bonus prvky

  • animácie pri načítaní
  • responzivita pre mobil
  • dark mode
  • vlastné ilustrácie alebo ikony

05

Checklist a hodnotenie

Toto môžeš použiť aj ako rýchly systém bodovania alebo ako zoznam, podľa ktorého si študenti sami skontrolujú, či majú hotovo.

Základný checklist

  • Stránka má jasný nadpis a fungujúcu štruktúru.
  • Obsah je rozdelený do sekcií a je ľahko čitateľný.
  • Použité sú farby, medzery a konzistentné fonty.
  • Sú tam tlačidlá alebo odkazy, ktoré dávajú zmysel.
  • Projekt vyzerá ako reálny web, nie len ako zoznam textov.

Návrh bodovania

1 bod

HTML štruktúra a povinné sekcie.

1 bod

CSS vizuál, medzery, farby a čitateľnosť.

1 bod

Layout cez flexbox alebo grid.

1 bod

Kreativita a celkový dojem.

Bonus

Hover efekty, responzivita, animácia alebo JS.

06

Ako si rozdeliť hodinu

Jednoduchý flow, aby študenti vedeli, čo robia na začiatku, počas práce aj na konci prezentácie.
