01

Kostra HTML dokumentu

Kazda HTML stranka ma zakladnu strukturu. Prehliadac podla nej vie, kde su informacie o stranke a kde je viditelny obsah.

Zapis

<!DOCTYPE html>
<html lang="sk">
  <head>
    <title>Moja stranka</title>
  </head>
  <body>
    <h1>Ahoj svet</h1>
    <p>Toto je obsah stranky.</p>
  </body>
</html>

Co znamena

  • <!DOCTYPE html> povie, ze ide o HTML5.
  • <html> je obal celeho dokumentu.
  • <head> obsahuje nastavenia a metadata.
  • <body> obsahuje to, co vidi navstevnik.

02

Co sa dava do <head>

Cast <head> sa nezobrazuje ako hlavny obsah stranky, ale je dolezita pre prehliadac, mobil, vyhladavace aj nacitanie stylov.

Priklad head

<head>
  <meta charset="UTF-8" />
  <meta name="viewport"
        content="width=device-width, initial-scale=1.0" />
  <meta name="description"
        content="Jednoducha HTML stranka" />
  <title>HTML a CSS jednoducho</title>
  <link rel="stylesheet" href="styles.css" />
</head>

Preco je to uzitocne

charset

Spravne zobrazi diakritiku a specialne znaky.

viewport

Pomaha, aby stranka fungovala dobre aj na mobile.

title

Nazov karty v prehliadaci a dolezity text pre SEO.

link

Pripoji externy CSS subor so stylmi.

04

Ako funguje CSS

CSS meni farby, medzery, velkost pisma a rozlozenie. HTML hovori, co je na stranke. CSS hovori, ako to ma vyzerat.

Priklad CSS

body {
  font-family: Arial, sans-serif;
  background: #f4efe8;
  color: #1f2933;
}

button {
  background: #d97706;
  color: white;
  border: none;
}

Jednoduche pravidlo

selektor + { vlastnost: hodnota; }

Napriklad: h1 { color: tomato; }

Selektor vyberie prvok a blok v zlozenych zatvorkach urci jeho vzhlad.

Tip: otvor tento subor v prehliadaci a skus menit texty, farby alebo pridat dalsi vlastny element.
